# MuseAi Sidebar - Installation Guide

## Overview
A dark, animated Manifest V3 side-panel extension for Chrome and Edge.

## Installation
1. Clone or download this repository
2. Open chrome://extensions
3. Enable "Developer mode"
4. Click "Load unpacked"
5. Select the extension folder

## Features
| Feature | Description |
|---------|-------------|
| Side Panel | Access Muse AI without leaving page |
| Dark Theme | Animated dark UI |
| MV3 | Latest Chrome extension standard |
| Cross-browser | Chrome + Edge support |

## Permissions
| Permission | Why |
|-----------|-----|
| sidePanel | Open side panel |
| activeTab | Access current page |
